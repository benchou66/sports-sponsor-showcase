01我的故事

競速甜心-姚宥米

『我不會走路，但我會跑步，而且可以跑向全世界』

I can't walk, but I can run, and run to the world.

出生於29週早產，僅1350公克，因腦室白質軟化症導致腦性麻痺，至今無法自行行走。幼年起便與復健、醫療密不可分，甚至在3歲時因肺炎插管並使用葉克膜，一度在生死邊緣徘徊。

在2018年，我接觸到腦麻專用的框架競速跑步車（Frame Runner），2022年，自費遠赴丹麥參加 Frame Running 訓練營，並意外站上國際賽場，奪下三面短跑金牌，成為亞洲首位參賽並獲獎的選手。迄今，我累積8金2銀2銅，自費參加過世界帕拉田徑賽、世界能力運動會等賽事，2024年世界排名第11。

當拿下第一面獎牌，我就夢想有一天能站上帕奧殿堂，但出國比賽與移地訓練需要有足夠的經費支持，平日需要的營養費用與練習後的累積起來的肌肉緊繃的放鬆，也需要昂貴的費用支撐，更不用說專業型的競技設備，希望能有足夠的支撐，可以以賽代訓，奪取更好的排名。

07我這樣訓練

訓練週期規劃

準備期

● 目標：

1. 建立全面體能基礎：肌力、耐力、柔韌性、協調性。

2. 建立良好規律作息與訓練習慣。

3. 改善與矯正技術動作。

4. 為後續專項強化與比賽期奠定基礎。

● 長度：8–12 週（依比賽時程調整）

● 階段劃分：

1. 一般準備期（前 4–6 週）→ 基礎體能 + 技術協調 → 打基礎（有氧、核心、協調、耐力）

2. 專項準備期（後 4–6 週）→ 專項技術 + 爆發力 + 模擬比賽 → 專項化（起跑、爆發力、模擬比賽、心理強化）

比賽期

維持速度與爆發力、強化比賽臨場表現，並透過減量調整讓運動員在比賽週達到最佳狀態，循序漸進，兼顧技術、心理、恢復，避免過度疲勞。

● 目標：

1. 進入比賽狀態，提升專項表現。

2. 調整最佳比賽體能（速度、爆發力、專項耐力）。

3. 強化心理素質，建立臨場自信。

4. 維持體能，避免過度疲勞與受傷。

● 長度：4–8 週（依比賽日程調整）

● 週期特性：

1. 比賽前 2–3 週：強度高、量適中（模擬比賽）。

2. 比賽前 1 週：逐步減量，保持狀態。

3. 比賽週：輕練習 + 調整，確保比賽巔峰表現。

過渡期

1. 訓練量/強度降低 40–60%。維持低–中等。

2. 多樣化活動的跨項運動（游泳、輕鬆騎自行車）。

3. 重視恢復：修復疲勞、避免傷害、睡眠、飲食、伸展、心理調適減少壓力。

4. 與教練回顧比賽與訓練成果。

5. 評估身心狀況、傷病情形。

6. 訂立下一訓練週期（準備期）的具體目標。

7. 逐步增加訓練量與強度 → 平順銜接準備期。

● 長度：約4–6 週（依比賽或主賽季結束狀況調整）

訓練方式

專項體能訓練

力量訓練（深蹲、抓舉啞鈴）➝ 爆發力（短跑）➝ 速度加速（衝刺、坡跑）➝ 有氧/間歇（耐力、乳酸耐受）➝ 核心穩定與敏捷柔軟 ➝ 恢復與放鬆

● 目標

1. 發揮爆發力與加速能力，提升速度極限

2. 建立基礎肌力、核心穩定、有氧耐力與乳酸耐受力

3. 增進柔軟度、協調性與敏捷性

專項運動技術

起跑 → 加速 → 中途跑 → 衝刺 → 專項細節，透過錄影回饋與反覆練習，精細化每個動作的協調與效率。

● 目標

1. 提升 起跑反應與加速效率

2. 建立正確 跑姿、擺臂與步頻控制

3. 優化中途跑與衝刺技術

專項運動戰術

涵蓋起跑 → 加速 → 中途跑 → 衝刺的全程策略（反應訓練、專注技巧、身體控制、專注自我表現、壓力應對），並結合心理戰術與比賽模擬，幫助選手在比賽中既能掌握節奏，又能臨場應變。

● 目標

1. 提升比賽中起跑至衝刺全程的戰術安排

2. 強化配速策略與動作經濟性

3. 養成臨場應變能力與心理抗壓性

4. 透過比賽模擬，累積比賽經驗

精神力訓練

結合心理建設素質培養、抗壓與堅持力訓練、自我激勵與身心恢復、檢討與反饋，讓比賽中能快速反應、保持放鬆，同時爆發最佳表現

● 目標

1. 培養快速反應 + 放鬆爆發的心理戰術核心

2. 建立比賽中的抗壓力、專注力與自我激勵

3. 調整心態與身體，達到比賽 最高峰狀態

4. 強化榮譽感與持續訓練的意志力
